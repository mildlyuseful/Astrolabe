# Astrolabe 0.2.0a2

Private internal-alpha artifact for daily driving. It is unsigned, carries no public support
commitment, and is not for distribution.

## What changed

- Added a per-user V1 installer definition and release-build staging contract.
- Added a first-run setup guide that projects existing device, input, integration, health, and
  consent authorities.
- Added executable, bundled AutoCAD DLL, and installer signing hooks that fail closed for public
  builds when credentials or verification are absent.
- Renamed the archived onedir root to `Astrolabe` and pinned the embedded Python patch version.
- Removed the obsolete SuperMini validation compile from CI. The retained XIAO protocol bench remains
  required until the official production firmware replaces it.
- Added the Vernier non-shipping UI study to source control while keeping all `ui_demo` content out
  of Python and onedir artifacts.

## Qualification boundary

This build still requires clean-account, daily-driver, supported-host, reversal, AltGr, Remote
Desktop, antivirus, and final-hardware evidence. Passing automated checks or packaged-resource smoke
does not close those gates.
