Onshape — Set Up

To use "cursor (under mouse)" orbit pivots, you need to install the Astrolabe helper userscript in your browser. Without it, Onshape falls back to screen-centre orbits.

Copied script source to clipboard!
Paste this code into Violentmonkey, Tampermonkey, or Greasemonkey.

Installation Steps:

  1. Install a userscript manager extension in your browser (e.g. Violentmonkey or Tampermonkey).
  2. Click the manager extension icon and select "Create a new script".
  3. Select the entire template code, delete it, and paste the Astrolabe script source.
  4. Save the script (Ctrl+S) and refresh your Onshape tab.
  5. In Onshape, make sure the SpaceMouse/3Dconnexion options are enabled in preferences.
